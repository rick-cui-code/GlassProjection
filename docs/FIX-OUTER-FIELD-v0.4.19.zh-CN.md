# v0.4.19 小缝响应与后台霍尔采样

## 现场原因

用户确认手机已打开一条缝并停住时，铰链读数约 3°、dighall 原始磁场绝对值约 1200，数字位仍为 0。该传感器携带的数字开关阈值为 681/1630，直接等待数字位变成 1 仍会让动画晚启动。

另一次检查发现应用的 dighall 读数已停留数十秒，而铰链事件仍在更新；启用 shell 进程采样后立即恢复连续数据。0.4.18 仅在应用里注册连续传感器，不能保证回到桌面后持续交付。

## 实现

- 仅对已验证的 `lhasa` 和 `ak0991x Digital Hall Sensor Non-wakeup` 生效。
- 原始磁场绝对值达到设备提供的闭合阈值 1630 时闭合；下降到该阈值的 90%（1467）时分离；中间区间保留前态，抑制抖动。1630 来自设备，90% 是根据本次采样选择的软件滞回边界，并非厂商规格。
- 已采集的合拢倾斜片段磁场约 1880 以上，用户确认的小缝约 1200，位于边界两侧。不能把整段含开合转换的日志最小值都当成合拢数据，也不能保证任意物理角度或外部磁场环境下均成立。
- 现有屏幕控制辅助进程以 shell UID 请求 20 ms 采样，通过既有约 40 ms 遥测通道传递带时间戳的最新样本。无需新配对、权限或常驻测试探针。
- 服务只接受 shell 调用传来的样本；空值、异常标定、乱序、重复样本不刷新状态。样本超过 500 ms 未更新时停止投影，新的有效样本自动恢复。
- 不再等待汇总 fold_status，真实分离后 0°/1°不会再次锁闭。保留内屏平展保护和不支持设备的旧信号回退。

## 验证

- 模型回归全部通过：数字位为 0 的 3°小缝、闭合倾斜、滞回区间、阈值边界、样本过期及恢复、重复/乱序/异常输入、原有角度动画与内屏平展保护。
- 辅助 DEX 已从源码重新生成；APK 构建成功，Lint 0 errors / 25 warnings。已同签名覆盖安装 versionCode 76 / 0.4.19，保留设置和配对身份，恢复原先开启的本应用无障碍服务。控制器确认 `DIRECT_CONTACT available=true uid=2000`，本轮未见应用崩溃。
- 用户停住小缝后确认“动画跟上了”。同步遥测为 rawAngle=3、angle=3、field=-1190.55、digitalBit=0、directContactStatus=1、projectionBlocked=false、sampleAge=22 ms。GPU 抓帧角度 2.9179482，已实际显示投影。
- 用户完全合拢并倾斜后确认“全程清晰，没有短暂模糊”。该段 20 个遥测样本中原始角度为 2°～17°，磁场绝对值 1923.3～1950.7501，有效接触全部为 0，投影角度全部为 0；样本年龄 8～67 ms。
- 安装后首段 40 个开合及倾斜样本的年龄为 14～75 ms；没有单独运行 HallTimingProbe。持续采样已由随应用启动的辅助进程承担。

现场日志保存在忽略提交的 `build/diagnostics/`。实际动画跟手程度仍需用安装后的真实开合验证，测试构造的角度不代表硬件一定及时上报。
