# v0.4.30 · 自动更新提示、后台续传与无障碍保留

- 「检查更新」移到首页最上方右侧。进入应用自动检查，有新版本时显示红点；短时间重复进入合并请求，离开应用后不进行定时检查。
- 下载独立于设置页面，由 dataSync 前台服务持续执行，返回首页、切换应用或旋转屏幕不会主动取消下载。通知栏提供进度与暂停。
- 支持持久化断点续传。暂停、断网或进程退出后保留已下载部分，再次下载从已有字节继续；服务器忽略 Range 时重新完整下载，范围异常不追加。换版本、缓存损坏及最终校验失败会丢弃不适用的片段。
- 下载完成自动打开安装确认；Android 拦截后台界面或手机锁屏时，保留完成通知，点击通知或回到应用继续安装。没有静默安装或绕过系统确认。
- 修复更新准备阶段主动关闭无障碍的问题：旧实现调用了 `ProjectionService.stop()` / `disableSelf()`，新版只暂停投影和助手，保留服务开关；取消安装后恢复运行，新 APK 由系统重新绑定服务。

## 升级提醒

版本 **0.4.30（versionCode 87）**，与 v0.4.27 / v0.4.28 / v0.4.29 同签名，可覆盖升级并保留设置和配对。

**旧版下载、安装本次更新时，仍使用旧版更新流程。** 因此这一次升级可能仍会关闭无障碍，需要手动开启一次；自动检查、后台续传和更新保留无障碍等改进，从运行 0.4.30 后生效。用户主动关闭的无障碍不会被强行重开；系统自行重置权限或限制服务绑定时仍需手动检查。

## 验证范围

模型回归测试、Android 构建与 Lint 通过（0 errors / 30 warnings）。续传测试覆盖断网保存、重新创建下载器后恢复、206 范围校验、200 忽略 Range、416 重试、损坏前缀拒绝、不同版本片段隔离、暂停及完整片段免重下校验。原有更新地址、镜像回退、完整性与签名检查保留。

本次未在用户手机上安装本版；后台生命周期、系统安装器交接和 HyperOS 对无障碍重新绑定的实际表现仍需升级后验证。
