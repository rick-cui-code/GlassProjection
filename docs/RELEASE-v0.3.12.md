# 玻璃投影 v0.3.12

首次公开发布当前实机验证版本。无需 root，通过 Shizuku 在手机上启动实时画面投影及切屏控制助手。

## 本版包含

- 内外屏玻璃开合投影；内屏右半保留原画面。
- 随距离变化的模糊和柔化黑边。
- 桌面与亮屏锁屏场景支持，无陀螺仪。
- 模糊默认 100%，展开切屏默认 60°，合拢切屏默认 120°，均可在 UI 调整。
- Shizuku 手机端助手、意外退出恢复、设置页不显示在最近任务中。
- 小米后台保护配置后，一键清理存活验证通过。

## 安装

下载下方 `GlassProjection-0.3.12.apk`，按[使用教程](https://github.com/spideytznn/GlassProjection/blob/main/docs/USAGE.zh-CN.md)启动并授权 Shizuku，开启「参考平面桌面动画」，配置自启动、无限制省电和后台锁定。手机重启后需重新启动 Shizuku。旧动画应用请先关闭无障碍。

目前仅在 Xiaomi 2608BPX34C / lhasa、Android 17 / HyperOS 4.0.11.0 验证，不是通用兼容包。外屏切屏仍可能短暂闪过系统交接中的另一页，尚未完全解决。

附件是已安装并验证的原始 **debug 签名 APK**，未重新编译或重新签名。自己构建的 APK 可能无法覆盖安装；签名密钥不公开。
