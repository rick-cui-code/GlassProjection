# v0.4.18 直接霍尔接触信号

> 后续实机复测发现：数字位在用户已打开的小缝（磁场约 1200）仍为闭合，且应用退到后台后连续传感器读数会停止更新。此版未完整解决小角度响应，由 0.4.19 的原始磁场判断和 shell 进程持续采样替代。下文保留本版实现及当时的验证记录。

## 问题与修正

0.4.17 增加闭合端点锁定后，仍依赖下一份 fold_status 汇总事件解锁。实机事件通常到约 11°～21°才更新，用户反馈已经打开，动画却没有跟上。模型中构造“2°的新分离事件”只能证明逻辑能处理它，不能证明固件真的在 2°发送该事件。

本轮发现并采集了 lhasa 的 `ak0991x Digital Hall Sensor Non-wakeup`（`xiaomi.sensor.dighall`）。它是连续型传感器，应用请求 20 ms 采样，不批处理。实测 values[0] 为 0 时接触、1 时分离；同一信号在闭合倾斜期间保持 0，而 fold_status 的 contact 字段可长时间停在 1。

采集示例：21:06:36.597 数字霍尔已报告闭合，汇总接触仍为分离；21:06:37.449 在此前铰链读数约 6°时数字霍尔已重新报告分离。另两次在此前读数约 8°时报告分离。直接闭合信号为 0 的采样区间内，原始角度曾达到 23°。这些数字是该次采样结果，不是通用物理角度阈值或响应时间保证。

0.4.18 在已验证的 lhasa/传感器名称组合上使用直接数字位作为闭合保护的优先来源：

- 直接接触=0：立即清除投影，不受噪声角度影响。
- 直接分离=1：立即解除闭合保护，不再等待 fold_status 更新，也不因角度再次落到 0°～1°而锁回去。
- 尚未收到首个有效直接样本：等待，不误显示投影。
- 乱序/重复/异常样本：忽略；不使用未标定的磁场阈值猜测分离。
- 无此传感器或注册失败：保留 0.4.17 端点保护回退；原有内屏平展姿态保护继续工作。

这消除了额外的软件等待，但动画仍受硬件实际分离信号和铰链读数的上报时机限制，不声称任意物理 1°必定已经可见。
