# v0.3.19 · 小角度动画修复与可调起始角度

## 安装后需要重启手机

**安装完成后，请重启手机一次，再重新启动 Shizuku，并检查、开启「玻璃投影」无障碍服务。**

升级顺序：旧版点「暂停动画」→ 安装下方 `GlassProjection-0.3.19.apk` → 重启手机 → 重新启动 Shizuku → 开启玻璃投影无障碍服务。

重启是清理旧版可能遗留投影层的升级步骤；已经遗留的锁屏 / 桌面残影不能靠覆盖安装可靠清除。本次测试手机在安装前正常暂停并确认旧图层已解除挂载后，完成了覆盖安装和服务恢复。

## 更新内容

- **修复小角度展开不出现动画**：测试机型的系统 CLOSED 状态在手机已经打开一条缝时仍可能保持，直到约 31° 才变化。新版改用该机型实测的接触分离状态，避免把这段真实展开误判为完全合拢，同时保留合拢倾斜保护。
- **新增「动画起始角度」**：默认 1°，可调 1–30°。超过设定角度后渐入，再展开 5° 达到完整效果；合拢时反向淡出。设置自动保存，恢复默认会还原为 1°。
- 小角度动画同样支持悬停和滑动恢复；保留现有模糊强度、内外屏切换角度、全局作用范围及投影层回收机制。

## 验证与适配范围

- 已在 Xiaomi `2608BPX34C / lhasa`、README 所列系统上安装验证，用户确认小角度动画恢复、完全合拢倾斜不再误模糊。
- 实测原始角度 2° / 4° 且接触分离时允许动画；完全合拢、角度漂至 12° 时仍禁止投影。
- 传感器回放与边界模型测试、Android debug 构建及 lint 通过；内置助手 DEX 与源码重建结果一致。
- 接触状态字段仅针对上述机型的实测协议适配，其他机型保留原检测路径。设为 1° 不代表所有设备都能在物理 1° 准确响应，效果仍受传感器精度与上报时机影响。

APK 为本次手机已安装验证的 debug 构建，沿用原签名，可覆盖安装并保留设置。附件提供 `SHA256SUMS-0.3.19.txt`。安装和后台配置见[使用教程](https://github.com/spideytznn/GlassProjection/blob/main/docs/USAGE.zh-CN.md)。
