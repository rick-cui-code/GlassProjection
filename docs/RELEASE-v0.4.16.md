# v0.4.16 · 内屏平展保护与跟手收尾

本版修复完全展开后倾斜整机误触发内屏动画，同时保留展开过程的原有角度跟随。无需新增权限，原来的无线配对、动画设置和外屏闭合保护保持不变。

## 更新内容

- **双条件平展保护**：仅在厂商上报“已展开”且铰链读数 ≥175° 时锁定。提前收到展开信号时继续跟随角度，不再立即清空画面或提前接管为固定时长动画。
- **锁定后防倾斜误触发**：读数因整机倾斜回落时保持清晰；有效姿态信号确认重新折叠后，恢复角度跟随。物理完全合拢仍优先清除效果。
- **快速处理收尾残差**：如果锁定时画面尚未跟到清晰端点，从当前渲染位置用 100 ms 平滑归位；不再采用开发阶段的 300 ms 收尾。
- **保持已有行为**：外屏正常角度跟随、模糊强度、拉伸裁切、切屏阈值及其他动画时长不变；悬停隐藏的效果不会因平展锁定而短暂重新出现。
- **补充回归测试**：覆盖两种信号到达顺序、175°边界、重复提前展开信号、锁定后角度抖动、再次折叠、闭合优先和完整姿态至渲染链路。

## 安装与升级

1. 升级前先在旧版点 **暂停动画**，确认本应用无障碍服务已关闭。
2. 下载 `GlassProjection-0.4.16.apk`。**v0.4.11 及当前同签名测试版可覆盖升级**，无需卸载或清除数据，保留设置与配对身份。
3. 沿用现有升级流程：安装后重启手机一次，清理旧版可能遗留的投影层；再开启无线调试，打开玻璃投影连接助手，最后检查并开启无障碍。配对授权仍有效时无需重新配对。

GitHub v0.4.0 附件签名与本版不同，不能直接覆盖。该旧版用户应先暂停并记录参数，再卸载旧版、安装新版，重新配对和开启无障碍。自行构建的 APK 也可能使用不同签名。

## 验证与适配范围

- 模型测试、两份助手 DEX 源码一致性检查、Android debug 构建及 lint 通过。
- 实机记录到：160°收到已展开信号仍未锁定，达到175°/176°后才锁定，再次折叠后正常解除；确认新助手加载并输出首帧。
- 适配范围仍为 Xiaomi `2608BPX34C / lhasa`、Android 17 / HyperOS 4.0.11.0。厂商姿态字段仅在已验证机型启用，其他机型沿用原回退路径。
- 启动时也要求两个条件同时满足；若已经平展但初始读数低于175°，保护会等待角度条件，不会仅凭展开信号提前锁定。
- 本版不包含双屏常亮等实验方案，不保证其他设备兼容、全部开合速度下的观感或持续120 fps。
