# v0.3.17 · 修复合拢倾斜误模糊与投影残留

## 安装后需要重启手机

**安装完成后，请重启手机一次，再重新启动 Shizuku，并检查、开启「玻璃投影」无障碍服务。**

从旧版升级请按以下顺序操作：

1. 在旧版玻璃投影中点「暂停动画」，确认本应用无障碍已关闭。
2. 下载下方 `GlassProjection-0.3.17.apk`，覆盖安装以保留设置。
3. **重启手机一次。** 旧版进程可能遗留投影图层，造成锁屏与桌面重叠；覆盖安装本身不能清除这些残影。
4. 打开 Shizuku 并重新启动服务，再开启玻璃投影的无障碍服务，确认「动画已就绪」。

新版增加了图层回收保护，但该保护不能替已经退出的旧版进程清理失效的图层句柄，因此首次升级也需要执行以上重启步骤。

## 修复内容

- 修复手机完全合拢时，倾斜整机导致铰链读数异常变化、重新出现模糊的问题。在支持的测试固件上，使用独立物理折叠信号判断闭合，合拢时禁止投影并释放切屏覆盖，打开后恢复角度跟随。
- 合拢时立即清除角度缓动和悬停回放状态，避免旧动画继续显示。
- 渲染助手持有本应用图层的回收句柄，在所属应用进程退出时隐藏并解除挂载；渲染循环退出前提交透明帧，减少锁屏或桌面画面残留。
- 更新助手版本，升级后重新加载内置渲染器；保留原有模糊强度、切屏角度、全局范围及恢复选项。

## 验证与适配范围

- 几何、场景、切屏方向、闭合异常角度回放、悬停恢复等 JVM 测试通过。
- 内置助手 DEX 与源码重建结果一致，Android debug 构建与 lint 通过。
- 测试手机上确认合拢倾斜不再误触发模糊；终止应用进程后，新版图层被回收，服务恢复运行。
- 物理闭合信号仅在 README 所列小米测试固件上验证；其他设备没有对应信号时保留原角度路径，不保证同样的修复效果。旧版已经遗留的残影仍需重启清理。

APK 使用与上一版相同的 debug 构建签名，可覆盖安装。附件同时提供 `SHA256SUMS-0.3.17.txt`。使用步骤和兼容范围见 [使用教程](https://github.com/spideytznn/GlassProjection/blob/main/docs/USAGE.zh-CN.md) 与 [README](https://github.com/spideytznn/GlassProjection)。
