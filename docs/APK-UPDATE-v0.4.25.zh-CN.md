# v0.4.25 应用内 APK 更新

设置页底部增加「检查更新」。点击后读取 `spideytznn/GlassProjection` 的 GitHub 最新正式 Release，按数值比较版本号，仅在发布版本高于当前版本时提供 APK 下载。

检查和下载均依次尝试 GitHub、`ghfast.top`、`gh-proxy.com`、`ghproxy.net`，网络超时、错误响应或校验失败后换源。每次下载保留独立临时文件，成功校验后才替换完整缓存；可随时取消。全部来源失败时弹窗显示 Release 链接，支持打开浏览器和复制链接；尚未取得发布信息时使用 latest 页面。

超过 1 MiB 的下载，持续 12 秒平均速度低于 64 KiB/s 时也换源；单源有连接、读取及整体时限，避免直连持续低速时长时间等待。

下载完成后检查 APK 大小、GitHub 提供的 SHA-256（若有）、APK 真实签名、与已安装版本相同的签名证书、包名和版本。使用 Android 官方 apksig 库验证 APK 签名，镜像返回的 HTML、损坏文件或异签名 APK 不交给安装程序。检查只访问本项目的 GitHub API 和 Release 附件，不发送配对信息、画面或应用黑名单。

随后申请系统「安装未知应用」权限（尚未允许时），暂停本应用动画并打开系统安装确认。安装后需要重新开启无障碍；如果取消安装，也可以手动重新开启。原设置、黑名单和配对通过同签名覆盖安装保留。没有模块替换、动态下载执行代码、独立更新签名密钥或后台定时检查。

## 今后发布

1. 增加 `versionCode` 与 `versionName`，用原 APK 签名密钥构建。
2. 在本仓库创建正式 Release，例如 `v0.4.26`，标为最新发布。
3. 上传 `GlassProjection-0.4.26.apk`。无需额外清单、热更新 ZIP 或服务器。

优先选择与版本对应的 `GlassProjection-版本.apk`。只有一个 APK 时也接受其他文件名；有多个且没有标准文件名时提供发布页供用户选择。当前版本规则接受 `v0.4.26` 或 `0.4.26` 等纯数字版本，不处理预发布版本。
