# v0.4.11 · 本机无线启动与配对流程简化

相较上一个公开版本 v0.4.0，本版将无线 ADB 配对与助手启动集成到应用内，并修复内外屏动画起步时的重影。无需额外安装 Shizuku，也无需 root 或电脑持续连接。

> **升级注意：本版沿用当前实机测试版签名，与 GitHub v0.4.0 附件签名不同，不能直接覆盖该旧公开版。** 当前同签名测试版可覆盖升级；旧公开版用户请先暂停动画并记录参数，再卸载旧版、安装新版，之后重新配对和开启无障碍。不要在没有记录设置时直接清除数据。安装后仍需重启手机一次。

## 更新内容

### 手机上完成配对和启动

- 主界面只保留一个「配对」按钮，移除「自动连接」和 Shizuku 备用入口。
- 未配对时，打开可拖动的系统配对小窗，同时进入无线调试；输入 6 位码即可，地址和端口自动发现。
- 已有有效配对时提示无需重复配对，自动尝试连接。系统明确拒绝旧授权时清除失效标记并进入重新配对，网络错误不会直接清除记录。
- 配对身份保存在应用私有且不备份的目录；正常覆盖安装保留，卸载或清除应用数据后需要重新配对。

### 小米设置和首次使用引导

- 使用系统小窗输入配对码，解决小米通知栏无法直接回复，以及普通悬浮控件在开发者设置里不可见的问题。
- 小米支持直接跳转「无线调试」页面；入口不可用时回到开发者选项，并保留手动备用入口。
- 增加开发者模式说明：**设置 → 我的设备 → 连续点击 OS 版本**，直到提示进入开发者模式。
- 引导顺序统一为 **先连接助手，再开启无障碍**，避免授权未完成就让用户开启动画服务。

### 修复配对成功却无法启动

- 修复 ADB 启动会话过早结束，助手尚未初始化就退出的问题。
- 等待独立助手完成连接后再关闭启动会话；已验证助手和渲染、切屏进程能继续运行，正常停止后也能重新连接。
- 增加不含配对码的启动阶段诊断，改善失效授权与连接失败提示。

### 优化内外屏动画起步

- 修复透明动画层与原位桌面叠加造成的重影和位置跳变：从原位清晰画面接入，再逐步增加视差与模糊。
- 内外屏同步优化小角度跟随，在 120 Hz 场景下使用按时间插值的过渡；反向开合及时响应。
- 保留现有模糊强度、拉伸裁切、中轴线衔接、自定义切屏角度和完全合拢保护。

## 安装与升级

1. 升级前在旧版点 **暂停动画**，确认本应用无障碍服务已关闭。
2. 下载 `GlassProjection-0.4.11.apk`。当前同签名测试版可覆盖安装；GitHub v0.4.0 用户按上面的签名迁移说明安装。
3. **安装后需要重启手机一次**，清理旧版本可能遗留的锁屏 / 桌面投影层。
4. 开启无线调试，打开玻璃投影点 **配对**。此前只为 Shizuku 配对过的用户，需要为玻璃投影完成一次独立配对；小米还需开启 **USB 调试（安全设置）**。
5. 助手连接成功后开启 **玻璃投影无障碍**，确认显示「动画已就绪」。建议配置自启动、无限制省电和后台保护。

重启后助手进程不会保留，需要重新开启无线调试并打开应用恢复连接；配对授权仍有效时无需重新配对。旧 Shizuku 兼容代码仍在 APK 内，默认启动路径和界面已切换为本机无线配对。

## 验证与范围

- 几何、内外屏起步、刷新率独立跟随、切屏和场景门控等模型测试通过。
- 两份助手 DEX 与源码重建一致，Android debug 构建及 lint 通过（0 错误）。
- 实机验证了系统小窗与无线调试同时显示、配对后独立启动、停止后重新连接，以及失效授权识别；起步重影修复已得到用户确认。
- 适配范围仍为 Xiaomi `2608BPX34C / lhasa`、Android 17 / HyperOS 4.0.11.0；不代表其他机型或系统版本已验证。
- 沿用系统单主屏切换路线，本版不包含常亮双屏或彻底消除硬件切屏黑屏的实验方案。
