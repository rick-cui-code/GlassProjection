# 使用教程

## 使用前

请先阅读首页的设备兼容范围。安装门槛是 Android 13，但当前用于减少系统切屏淡入的显示器挂载路径需要 Android 14+，只有 README 中列出的测试固件经过验证。系统允许安装不代表已经适配。

从 GitHub Release 下载 APK。首次安装按手机提示允许当前文件管理器或浏览器安装应用；无需 root。请不要同时启用其他开合动画应用的无障碍服务。

**v0.4.11 使用当前实机测试签名，与 GitHub v0.4.0 签名不同，不能直接覆盖该公开版。** 旧公开版用户先暂停动画并记录参数，再卸载安装；需要重新配对和开启无障碍。当前同签名测试版可以覆盖安装保留设置。

**安装后需要重启手机一次，再开启无线调试、打开玻璃投影连接助手，最后检查并开启无障碍服务。** 升级前请先在旧版点「暂停动画」。旧版可能留下锁屏投影层，导致桌面与锁屏重叠；覆盖安装不能清掉已经遗留的图层，重启用于清理残影。

## 配对并启动助手

1. 小米没有开发者选项时，进入 **设置 → 我的设备 → 连续点击 OS 版本**，直到提示进入开发者模式。应用也提供说明和系统设置入口。
2. 开启无线调试；小米还需要单独开启 **USB 调试（安全设置）**。
3. 在玻璃投影中点 **配对**。没有有效记录时，会打开系统配对小窗并跳转无线调试；选择使用配对码配对设备，在小窗输入 6 位码。地址和端口自动发现，不用抄写。可以拖动小窗避开系统配对码。
4. 等待提示助手已连接，再进行下一步无障碍设置。已有有效配对时提示无需重复配对；授权失效时重新进入配对流程。无线调试关闭或网络不可用不会直接清除配对记录。

不需要安装 Shizuku、root 或电脑持续连接。旧版在 Shizuku 中建立的配对不会自动成为玻璃投影的配对，需要在本应用完成一次。系统不支持直达时可从开发者选项进入无线调试；详见[本机无线启动](WIRELESS-SETUP.zh-CN.md)。

## 开启无障碍

助手连接成功后，在玻璃投影中点击「开启无障碍」，找到「玻璃投影」并打开。下载的应用可能被放在「已下载的应用」分组中。

如果系统阻止开启并提示受限设置，先进入玻璃投影的应用信息页，按系统提示允许受限设置，再返回无障碍页面。此确认应由设备使用者完成。

返回玻璃投影，状态应变成「动画已就绪」。回到系统桌面开合手机；如需在应用内也生效，打开「作用范围 → 全局启用」。锁屏动画在屏幕点亮、系统锁屏可见时工作，不会绕过锁屏认证。

## 小米后台设置

应用内「后台运行设置」进入本应用的系统信息页。确认：

- **自启动**：允许。
- **省电策略**：无限制。
- **后台锁定 / 清理保护**：开启。不同版本入口不同，可在手机管家的设置中寻找内存加速的锁定应用名单。不要把它与要求密码的“应用锁”混淆。

菜单以当前手机显示为准。默认无线启动路径不依赖 Shizuku 后台服务。

完成后执行一次自己平常使用的一键清理，再回桌面开合，确认动画仍在。隐藏最近任务卡片本身并不能防止系统终止进程。

## 调整效果

- **模糊强度**：100% 是当前默认效果；0% 只去掉模糊；200% 更强。
- **动画起始角度**：1～30°，默认 1°。超过设定角度后逐渐增加视差和模糊，合拢时反向收尾；v0.4.11 修复透明动画层与原位图标叠加产生的起步重影。设置自动保存，「恢复默认」会还原为 1°，不改变切屏角度。完全合拢保护优先：支持物理开合检测的手机必须先上报已展开，因此设为 1° 不保证在物理 1° 时已经可见；其他设备的传感器行为仍需适配。

0.3.19 修正已验证的 lhasa 机型小角度不起动画：系统的 `CLOSED` 状态在已经打开一条缝时仍可能保持，直到约 31° 才切换，不能等同于完全合拢。该机型改用实测的接触分离状态，让起始角度设置在小角度展开时生效，同时保留合拢倾斜保护。实际响应仍受传感器精度和上报时机限制。
- **展开时切到内屏**：默认 60°。
- **合拢时切到外屏**：默认 120°。
- **全局启用**：默认关闭。打开后，动画也用于应用内。
- **悬停等待时间**：1～10 秒，默认 3 秒。整段时间内角度摆幅不超过 10° 时，约 220 毫秒平滑恢复正常画面。
- **滑动恢复正常画面**：默认关闭。开启后手指滑动即可提前恢复，静态空白处也有效；轻点和小幅抖动不触发。
- **恢复默认**：模糊和切屏角度恢复默认值，等待时间恢复 3 秒、关闭滑动恢复；保留全局作用范围选择。
- **暂停动画**：关闭本应用无障碍并停止助手，释放系统切屏覆盖。重新使用时需要再次开启无障碍。

完全合拢约为 0°、平整约为 180°。角度控制带有方向判断；打开一半再合回去时，不会简单地按同一阈值反复切屏。自定义切屏在所选作用范围内接管；关闭全局时，只用于支持的桌面/锁屏场景。悬停或滑动恢复只退出视觉效果，不释放切屏控制，避免半折使用时突然切屏。继续开合超过 10° 后重新出现动画。

## 常见问题

### 完全合拢后倾斜手机仍然模糊

请升级到当前版本：测试机型使用接触分离状态区分完全合拢与小角度展开，避免倾斜误模糊，同时修复早先闭合判断过宽导致动画出现太晚的问题。按安装说明重启手机、重新连接助手。

### 安装后锁屏与桌面重叠

这是旧进程可能遗留的投影图层。**安装后重启手机一次**，再连接助手并检查本应用无障碍状态。仅重装 APK 或重新打开应用可能无法清除旧残影。新版增加了进程退出回收，但无法替已经退出的旧版进程清理失效的图层句柄。

### 开了无障碍却没有动画

确认应用中的助手已连接。尚未连接时开启无线调试，返回应用点「配对」检查已有授权；系统授权被移除时重新配对。被系统强行停止后，应重新打开应用并检查无障碍。若仍不恢复，手动关闭再开启本应用的无障碍服务。

### 滑动恢复没有触发

先确认该开关已开启、助手已连接。需在半折动画仍可见时测试；如果已经恢复正常，先继续开合超过 10° 让动画重新出现，再在静态区域滑动。轻点不触发。系统必须支持只观察触摸的接口并授予 shell 相应权限；其他设备不保证支持，悬停计时仍可使用。

### 一键清理后无障碍掉了

小米某些清理策略会把清理处理为强行停止。确认自启动、无限制省电、后台锁定三项，不要只设置省电。主动在应用信息页点“结束运行”仍可能关闭服务，应用不会自动推翻这个操作。

### 退出应用或重启后还可用吗

正常离开应用界面不会主动停止动画。手机重启后需要重新开启无线调试并打开应用，让保存的身份自动连接，再检查无障碍状态；一般不需要重新配对。系统关闭无线调试时不承诺无操作恢复。默认启动路径不依赖 Shizuku。

### 外屏偶尔闪过另一页

这是当前已知的系统桌面切屏交接问题，尚未完全解决。此版本没有引入桌面分页截图缓存，也没有常亮双屏方案。可以先恢复默认参数；如影响使用，暂停动画即可。

### 要升级或卸载

同包名、同签名的 APK 可以覆盖安装并保留设置。如果提示签名不一致，不要直接清除数据：先记录模糊和角度设置，再决定是否卸载重装。自己编译的 debug 密钥通常与发布包不同。

升级顺序：**旧版暂停动画 → 安装新版 → 重启手机一次 → 开启无线调试并在玻璃投影中连接助手 → 检查并开启无障碍服务**。请不要省略安装后的重启步骤。

卸载前建议在应用里暂停动画；也可在系统无障碍中关闭服务，再卸载 APK。用户不需要手工清理系统文件或修改全局动画倍率。
