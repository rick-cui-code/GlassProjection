# v0.4.28 · 性能优化、应用黑名单与 APK 更新

发布版本为 **0.4.28（versionCode 85）**，比本机测试版 **0.4.27（84）** 高一版，可用于测试应用内「检查更新」。

## 更新内容

- 改善小角度开合判断：使用已适配机型的磁场采样识别接触分离，完全合拢时倾斜保持清晰；保留内屏平展保护。
- 优化空闲功耗：透明后暂停捕获与持续绘制，减少重复状态通信和无变化画面的绘制；开合时及时唤醒，优化快速运动与中途反向跟随。
- 加快内外屏交接：提前渐暗范围从 12° 缩至 8°，就绪后的渐亮从 180 ms 缩至 120 ms。
- 新增带图标和搜索的应用黑名单，所选应用不参与动画。
- 新增「检查更新」：读取 GitHub 最新正式 Release，下载 APK；支持镜像回退、大小/哈希/签名/包名/版本检查。全部来源失败时提供 Release 链接。无后台定时检查。
- 默认保留配对小窗应用，通知配对移至「更多配对方式」；仅删除悬浮窗配对及悬浮窗权限。
- 在适配的小米系统中，管理无障碍直接进入「已下载的应用」；其他系统保留兼容回退。
- 合并远端已有的传感器异常保护：两种物理来源均不可用时禁止仅凭铰链读数启动投影；有效磁场采样仍可支持小角度跟随。

## 安装与更新测试

与本机 v0.4.27 使用相同签名，可覆盖升级并保留设置、黑名单和配对身份。GitHub v0.4.11 / v0.4.16 / v0.4.17 等异签名旧版不能直接覆盖；需要重装时先记录参数，卸载会清除数据。

v0.4.27 用户打开应用底部「检查更新」，在更新页再次点击「检查更新」，应显示 v0.4.28。下载完成后按提示允许安装并确认系统安装。应用在安装前暂停动画，完成后打开应用并重新开启无障碍；取消安装后也需手动恢复无障碍。手动下载用户请先暂停动画再覆盖安装。

## 验证范围

模型回归测试、两份助手 DEX 与源码一致性检查、Android 构建和 Lint 通过。覆盖传感器异常、磁场恢复、快速反向、闭合与平展保护、空闲唤醒、黑名单和更新换源校验。APK 签名与本机 0.4.27 核对一致。

此前测试版已由用户确认小缝跟手、合拢倾斜清晰及性能优化后开合无异常；这些不是完整续航测试。0.4.28 的实际更新安装流程留给当前本机 0.4.27 测试，发布时不预先覆盖安装。
