# v0.4.17 · 修复外屏闭合倾斜误模糊

修复闭合传感器异常时，手机已经合上但倾斜整机仍可能启动外屏模糊的问题。

## 更新内容

- 已适配的 `lhasa` 机型在闭合传感器缺失、注册失败或访问被拒绝时保持禁止投影，避免退回仅凭铰链角度启动动画。
- 缺少闭合信号时清除角度缓动、悬停状态和切屏覆盖；恢复传感器并重连无障碍服务后，收到有效接触分离信号即可恢复小角度动画。
- 保留正常小角度开合、内屏平展保护及现有动画参数，补充传感器异常回归测试。

## 安装与升级

**本版使用新的本机 Debug 签名，不能直接覆盖 GitHub v0.4.11 / v0.4.16。** 本次同签名的 `GlassProjection-0.4.16-closed-tilt-fix-debug.apk` 测试包可以覆盖升级。

旧发布版用户如需安装，请先暂停动画并记录参数，再卸载旧版、安装 `GlassProjection-0.4.17.apk`。卸载会清除设置和配对身份，需要重新配对和开启无障碍。安装后沿用重启手机一次的流程，清理旧版可能遗留的投影层。

## 验证范围

模型回归测试、两份助手 DEX 源码一致性校验、Android debug 构建和 lint 已通过（0 错误、25 警告），APK 签名校验通过。尚未完成实机复测，不能据此认定所有外屏倾斜模糊情况均已解决。传感器始终不可用时，本版会保持动画禁用。
